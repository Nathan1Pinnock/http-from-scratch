http-from-scratch

This page was served by an HTTP/1.1 server written in C# on raw TCP sockets. No Kestrel, no HttpListener: the request you just sent was parsed by hand.

Open the developer tools and look at the response headers. Reload the page and you should get a 304 Not Modified for this file and the stylesheet.

  • /hello comes from a handler in code.
  • curl -d "ping" localhost:8080/echo echoes a request body back.
  • /missing is a 404.
